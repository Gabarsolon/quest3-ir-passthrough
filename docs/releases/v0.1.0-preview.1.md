RAM-only stereo IR replacement for Quest 3 system passthrough, tested on Horizon
OS v79 build 51154110174900520. Temporary root must already be active.

- Replaces the compositor's RGB camera textures with calibrated stereo IR.
- Image-space motion correction preserves the native camera/menu pose buffers.
- Holds each IR capture across the eye's whole frame to prevent mid-frame image
  switches. The user confirmed the final view: "seems perfect now".
- About 60 changed IR images/sec per eye in the measured interval; the headset
  display held 90 Hz. Source resolution remains 640x512.
- Linear filtering and anti-aliasing off by default. Cubic, Snapdragon GSR1 and
  edge anti-aliasing remain optional for each run.
- Wireless ADB startup keeps the hooks alive during discovery and map transfer.
- Stop, host-heartbeat loss, or reboot restores normal RGB. New headset binaries,
  frames and logs stay in tmpfs; no firmware or system partition is written.

Run with Python, NumPy, Frida 17.17.0, LLVM clang, authorized ADB and active
temporary root:

```powershell
python tools/system_passthrough.py
```

Use `python tools/system_passthrough.py --stop` to restore RGB. Optional image
enhancements: `--filter sgsr --sgsr-sharpness 1.0 --aa edge`.

This is a prototype for one checked firmware build. Other apps/layouts and
long-term behavior remain unverified. The remap retains the compositor's RGB
depth/translation assumptions; close-range parallax and source detail have limits.
Root recovery is a separate operation; this release does not run the exploit.
